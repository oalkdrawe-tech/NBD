نبض بلس | NABD PLUS — نسخة التصميم الداكن والبرتقالي والربط الرسمي
====================================================================

هذه حزمة مشروع Node.js وليست ملف HTML فقط. الأرقام التجريبية أزيلت من لوحة التحكم؛ قبل الربط تظهر شرطات (—) بدل أرقام مصطنعة. لن تُعرض بيانات الحساب إلا بعد أن يرجعها Instagram API.

ما يعمل في المشروع بعد اكتمال إعداد Meta:
- تسجيل دخول Instagram الرسمي OAuth (لا نطلب كلمة مرورك داخل نبض بلس).
- جلب معلومات الحساب التي تسمح بها Meta، مثل اسم المستخدم وعدد المتابعين والمنشورات إذا كانت متاحة.
- قراءة المنشورات والتعليقات والرد اليدوي على تعليق بعد الضغط على زر الإرسال.
- لا يوجد رد آلي صامت في هذه النسخة؛ الرد التلقائي يحتاج إعداد Webhooks واختبارًا منفصلًا.
- أفكار المحتوى والمهام المحلية أدوات مساعدة، وليست بيانات مسحوبة من إنستغرام.

خطوات الربط الحقيقي (تحتاج إعدادًا مرة واحدة):
1) حوّل حساب Instagram إلى Creator أو Business إن لم يكن احترافيًا.
2) افتح Meta for Developers: https://developers.facebook.com/ وأنشئ تطبيقًا مناسبًا لاستخدام Instagram API with Instagram Login.
3) من إعدادات التطبيق أضف إعداد Instagram Login / Business Login for Instagram حسب واجهة Meta الحالية، وأدخل رابط OAuth Redirect URI الذي سيظهر بعد نشر موقعك. يجب أن يكون الرابط مطابقًا تمامًا لمتغير META_REDIRECT_URI.
4) انشر هذا المشروع كـ Web Service على استضافة تدعم Node.js وHTTPS (مثل Render). ارفع محتويات المجلد إلى مستودع GitHub، ثم أنشئ Web Service من المستودع.
5) Build Command: npm install. Start Command: npm start.
6) من إعدادات Environment في الاستضافة أضف القيم التالية، ولا تضع الأسرار في index.html أو في رسالة دردشة:
   SESSION_SECRET = نص طويل عشوائي وسري
   META_APP_ID = معرّف تطبيق Meta
   META_APP_SECRET = سر التطبيق (سري للغاية)
   META_REDIRECT_URI = https://YOUR-DOMAIN/auth/instagram/callback
   META_API_VERSION = إصدار Graph API مدعوم حاليًا من Meta (تحقق من لوحة الوثائق قبل وضعه)
7) في لوحة Meta أضف رابط العودة نفسه حرفيًا: https://YOUR-DOMAIN/auth/instagram/callback ثم احفظ وأعد نشر الخدمة.
8) افتح رابط موقعك المنشور (ليس ملف index.html مباشرة)، ثم الإعدادات والربط > «ربط حساب Instagram رسميًا». أكمل تسجيل الدخول في صفحة Instagram الرسمية ووافق فقط على الصلاحيات التي تفهمها.
9) بعد الرجوع للموقع، اضغط «تحديث البيانات» ثم «تحديث المنشورات». جرّب الرد اليدوي على تعليق تملكه.

ملاحظات مهمة:
- لا ترسل كلمة مرور Instagram أو META_APP_SECRET أو Access Token لأي شخص، ولا تضعها في HTML أو GitHub.
- الكتابة في خانة اسم المستخدم لا تربط الحساب بحد ذاتها؛ الربط يتم عبر OAuth الرسمي فقط.
- الحساب يجب أن يكون Creator أو Business. بعض الصلاحيات تحتاج إعدادًا إضافيًا أو مراجعة تطبيق Meta، خصوصًا عند خدمة حسابات أشخاص آخرين.
- قد لا تكون كل مؤشرات Insights متاحة لكل حساب أو في كل فترة. لذلك تبقى القيمة — إذا لم تُرجع Meta قيمة حقيقية.
- هذه الحزمة لا تنشئ تطبيق Meta نيابةً عنك ولا تحتوي معرّف تطبيقك أو أسراره. لا يمكن لأي ملف ZIP أن يتجاوز موافقة Meta.
- خادم الجلسات الحالي يستخدم مخزن ذاكرة؛ إعادة تشغيل الخدمة قد تتطلب تسجيل الدخول من جديد. لا تعتبره جاهزًا لخدمة مستخدمين متعددين قبل إضافة مخزن جلسات دائم ومراجعة أمنية.
- الرد التلقائي يحتاج Webhooks، إعداد اشتراك التعليقات، منطقًا يمنع التكرار والردود غير المناسبة، واختبارًا قبل تشغيله. لا تفعّله قبل التأكد من سلوكه.
- Claude.ai ليس هو Claude API؛ توليد الردود عبر API قد تكون له تكلفة. هذه النسخة لا تدّعي أنها متصلة بClaude.
