كيف سيعمل سهم النمو؟

نحفظ نقاط القياس المسموح بها دوريًا، ثم نقارنها بالفترة السابقة. بعض مؤشرات الجمهور تعتمد على ما توفره Meta للحساب والصلاحيات الممنوحة.

ملاحظة: لا توفر واجهة Instagram بالضرورة رقمًا لحظيًا لكل متابع جديد. قد يعتمد التحديث على مؤشرات وإحصاءات متاحة، لذلك لن نعدّ بظهور كل متابعة فور حدوثها.

مساعد صياغة الرد

اكتب التعليق وحدد النبرة، وسيجهز لك ردًا مقترحًا محليًا.

تعليقات حسابك الحقيقي

بعد الربط، اختر منشورًا لعرض التعليقات والرد عليها. الإرسال لا يتم إلا عند الضغط على زر الرد.

بانتظار ربط الحساب.
الرد التلقائي دون ضغط يحتاج إعداد Webhooks ومراجعة صلاحيات إضافية؛ هذه النسخة تتيح عرض التعليقات والرد يدويًا بعد نجاح الربط.

أفكار تخلي محتواك يبرز ✨

ولّد أفكارًا قابلة للتخصيص حسب مجال حسابك. يمكنك نسخ الفكرة إلى مساعد ذكاء اصطناعي لتوسيعها.

💡
الأفكار تُنشأ بقواعد محلية في هذه النسخة ولا تعتمد على Claude أو نموذج خارجي. الربط بنموذج ذكاء اصطناعي يحتاج تكاملًا منفصلًا وقد تكون له حدود مجانية.

ربط الحساب الحقيقي

غير متصل

اكتب اسم المستخدم للتعرّف عليه داخل اللوحة، ثم اضغط ربط الحساب وسجّل الدخول في صفحة Instagram الرسمية. كتابة الاسم وحدها لا تمنح الموقع صلاحية الوصول.

حالة الربط: لم يتم الاتصال بعد. يتطلب إعداد متغيرات Meta في السيرفر أولًا.

1. إعداد تطبيق Meta

أنشئ تطبيقًا في Meta for Developers وأضف رابط العودة OAuth المطابق للدومين الذي تنشر عليه الموقع.

افتح Meta for Developers ↗

2. صلاحيات API

تُطلب الصلاحيات حسب الميزات المطلوبة، مثل قراءة البيانات وإدارة التعليقات. قد يتطلب الوصول لمستخدمين آخرين مراجعة التطبيق.

وثائق Instagram الرسمية ↗

3. ذكاء اصطناعي

يمكن ربط نموذج متاح مجانًا أو بخطة محدودة، لكن لا تضع مفاتيح API السرية داخل ملف HTML العام.

فتح Claude ↗

4. الخصوصية والأمان

لا تشارك كلمة مرور إنستغرام مع أي موقع. استخدم تسجيل الدخول الرسمي ولا تخزن رموز الوصول داخل المتصفح.

مهم: لن يطلب نبض بلس كلمة مرور Instagram داخل الموقع. تسجيل الدخول يتم عبر صفحة Instagram الرسمية، ويُحفظ رمز الوصول في جلسة الخادم وليس في كود الواجهة.
